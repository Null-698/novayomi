<h1 align="center">Novayomi</h1>

<p align="center">An iOS-focused novel reader based on <a href="https://github.com/kodjodevf/mangayomi">Mangayomi</a>.</p>

> [!WARNING]
> Novayomi does not host novels or provide novel content. Novel sources are external and are not affiliated with this project.

## Features

- Read novels from supported sources or local files.
- Customize your reading settings.
- Organize your novel library with categories.
- Read offline and create local backups.
- Light and dark themes.
